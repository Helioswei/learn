# Kotlin Android 开发教程

从语言特性到 Android 实战，为有编程基础的开发者打造的系统化学习路径。涵盖 Kotlin 语法、协程、Jetpack Compose、架构设计等核心主题，共 16 章。

## 在线阅读

部署到 GitHub Pages 后，访问：

```
https://<your-username>.github.io/kotlin-tutorial/
```

## 教程特色

- **思维导师体系**：每章由一位"导师"（费曼、柯南、福尔摩斯、诸葛亮等）以独特的思维方式引导讲解，让抽象概念具象化
- **C++ 开发者对照**：在语法、面向对象、协程等章节提供 C++ 对比说明，帮助有 C++ 背景的读者快速建立知识桥梁
- **章末互动练习**：每章附 3-5 道练习题，分入门/进阶/挑战三档难度，含折叠提示与参考答案
- **零依赖**：纯 HTML + CSS 静态站点，无需构建工具、无 JavaScript 框架，浏览器直接打开即可阅读

## 本地预览

```bash
# 在项目根目录启动本地服务器
python3 -m http.server 8000
```

然后在浏览器中访问 `http://localhost:8000`。

或者直接用浏览器打开 `index.html` 文件。

## 技术栈

- **HTML5** — 语义化页面结构
- **CSS3** — Catppuccin 风格代码高亮，响应式布局
- 无 JavaScript、无构建工具、无第三方依赖
